This site started life as a few static HTML files and a single stylesheet. That
was deliberate — it loaded instantly and there was nothing to maintain. But I
wanted a blog, and I wanted room to grow, so I rebuilt it on **Next.js**.

## What changed

- **Next.js (App Router)** for routing, metadata, and static generation.
- **Tailwind CSS v4** for styling, with the old design ported into theme tokens.
- **shadcn/ui** for components, themed to match the existing dark, monospace,
  orange-accented look.
- **MDX** for writing posts like this one.

## What stayed the same

The visual design is intentionally unchanged: `#0d0d0d` background, monospace
type, and that orange accent. If you can't tell it's a different stack, that's
the point.

```ts
// Posts are just MDX files with frontmatter.
export type PostFrontmatter = {
  title: string;
  description: string;
  date: string;
};
```
